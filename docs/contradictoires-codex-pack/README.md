## Governing principle

This project must be delivered in small, runnable slices.

- Codex may complete non-visual foundations autonomously when they are reversible, tested, and do not silently decide product behavior.
- Every checkpoint that changes what the Founder sees or how the Founder interacts with the product must stop for Founder visual review.
- Founder review is performed by using the actual runnable product, not by reading implementation descriptions.
- A later checkpoint may refine an accepted screen, but Codex must not replace accepted interaction direction without an explicit proposal.

## Product in one sentence

A private internal application that lets an accountant create normal commercial documents and generate a configurable set of “les contradictoires” from an existing main document, with reusable companies, clients, templates, pricing rules, PDF output, and editable Excel output.

## Important scope boundary

The first version must make the manual workflow excellent. Automatic extraction from uploaded PDFs or images is a later capability. In the first version, an uploaded source document is shown as a reference beside the editable document.
